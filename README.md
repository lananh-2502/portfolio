# Vũ Thị Lan Anh Portfolio

Next.js portfolio with Tailwind CSS, Framer Motion, supplied portfolio media, interactive case studies, and a Web3Forms-to-mailto contact path.

## Run locally

```bash
pnpm install
pnpm dev
```

Copy `.env.example` to `.env.local` and set `WEB3FORMS_ACCESS_KEY` to activate the server-side form. Without a key, the form opens a prefilled email to `lananhvu.2502@gmail.com`.

## Production

```bash
pnpm build
pnpm start
```
